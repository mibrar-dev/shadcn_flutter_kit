Why this kit

Everything shadcn got right, in Dart.

No design-system lock-in. The CLI copies real source into your app; from then on it is yours to edit, theme, and ship.

Installable alone

Each component resolves its own dependencies. flutter_shadcn add dialog pulls exactly what dialog needs — nothing more.

Token theming · 42 presets

Same token names as shadcn CSS — background, primary, chart-1…5, radius. Switch presets with a 300ms colour morph.

Widgets-only Flutter

Built on package:flutter/widgets.dart only. No Material, no Cupertino — a sibling of material_ui, not a wrapper.

User-owned theme files

Per-component button_theme.dart holds your values only. CLI updates never overwrite it. Studio-ready editor schema included.

Accessible + keyboard

Focus rings from the ring token, arrow-key navigation, Esc dismissal, and semantics baked into every primitive.

Verified by construction

Single-owner symbols, layered imports, and flutter analyze gates keep all 118 components compiling together.

How it works

Init → add → own the code.

Three commands stand between you and a themed component in your app.

01

Init

Scaffold the theme host and token files for your chosen preset.

$ flutter_shadcn init --preset modern-minimal
02

Add

Copy real source for one component plus its resolved dependencies.

$ flutter_shadcn add dialog calendar # two at once
03

Own

Edit the widget or its theme file in place. Updates never clobber you.

final theme = ButtonTheme(// your values
  primary: ThemeRef.primary,
  radius: 12,
);
