Introduction

shadcn_flutter_kit is a shadcn/ui-style design system for Flutter, shipped as copy-paste source you own.

Every component is installable alone: one directory, one meta.json manifest, and a deterministic dependency list. The CLI copies real Dart into lib/ui/shadcn/ — there is no versioned package to fight.

Widgets only. The kit builds on package:flutter/widgets.dart. If you see a Material import, that is a bug — please report it.

How it fits your app

Global tokens (background, primary, chart-1…5, radius) mirror shadcn CSS variables 1:1. Each component reads tokens through its own theme class, so a preset switch re-skins the whole app with a 300ms colour morph and zero layout shift.

What you own

After flutter_shadcn add button you own button.dart (widget), button_style.dart (token defaults, replaced on update), and button_theme.dart (your overrides, never overwritten).

Next steps

Install the CLI and add your first component, or browse the 118-component index.

$ dart pub global activate flutter_shadcn
$ flutter_shadcn init --preset modern-minimal
$ flutter_shadcn add button
