Button

1 filestable

One consolidated widget with a variant table — no class-per-variant. Clickable primitive owns hover, focus, press, keyboard, and semantics.

$ flutter_shadcn add button
# copy these into lib/ui/shadcn/
button/button.dart ← widget + variants
button/button_style.dart ← registry-owned defaults
button/button_theme.dart ← your overrides (keep)
