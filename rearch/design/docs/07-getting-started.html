Getting started

Four steps, about two minutes. You will end with a themed button running in your own app — source included.

  1. Install the CLI

    ~20s

    One global activate. Requires Dart 3.4+; no Flutter version lock.

    $ dart pub global activate flutter_shadcn

  2. Init your app

    ~15s

    Run inside your Flutter project. Scaffolds lib/ui/shadcn/, the token host, and one app_theme.dart for your preset.

    $ flutter_shadcn init --preset modern-minimal

  3. Add components

    ~10s each

    Name what you need. Shared code and the owning component resolve automatically — dialog pulls the overlay primitive, never a duplicate.

    $ flutter_shadcn add button dialog calendar

  4. Theme it

    ongoing

    Use it, then make it yours. Widget props win; then scoped ComponentTheme; then your button_theme.dart; then token defaults.

    import 'package:myapp/ui/shadcn/button.dart';

    Button(variant: ButtonVariant.secondary,
      onPressed: _save,
      child: Text('Save changes'),
    )

Verify

flutter analyze reports zero new issues.
No material.dart import under lib/ui/shadcn/.
Toggle OS dark mode — the button follows via tokens.
