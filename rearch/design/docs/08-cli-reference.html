CLI reference

Six commands. Every install is topological, single-owner checked, and preserves your *_theme.dart files.

add most used

Copy components plus resolved dependencies into lib/ui/shadcn/. Refuses when a symbol would be defined twice.

$ flutter_shadcn add dialog calendar --preset modern-minimal
FlagDefaultNotes
--presetcurrentRegenerate app_theme for this preset
--dry-runfalseList files without writing
--forcefalseOverwrite registry-owned files only; themes kept

init

Scaffold the theme host, token files, and component registry for installed components only.

$ flutter_shadcn init --preset modern-minimal --dir lib/ui/shadcn
FlagDefaultNotes
--presetmodern-minimalAny of the 42 presets
--dirlib/ui/shadcnInstall root

theme

Import shadcn / tweakcn CSS into canonical JSON, then generate app_theme.dart. Missing tokens derive.

$ flutter_shadcn theme import theme.css
$ flutter_shadcn theme use claude # switch preset, keep overrides
SubcommandNotes
import <file.css | url>Parses :root + .dark, oklch/hsl/hex/rgb
use <preset>Regenerates app_theme.dart only

list · remove · doctor

Inspect, prune, and verify an installation.

$ flutter_shadcn list # installed components + owners
$ flutter_shadcn remove calendar # keeps shared code others use
$ flutter_shadcn doctor # single-owner + layer check
