Bugs fixed / behaviours corrected:

- `package:flutter/material.dart` import removed (old imported `Colors`).
- `data_widget` and `gap` dependencies removed (foundation `Data`/`Gap` only).
- The mutable static `DrawerOverlay._currentLayer` layer stack is gone; the
  drawer is a single `ModalRoute` (dialog pilot, decision D2).
- `SheetOverlayHandler` is no longer owned by the component: `Card` and the
  menus use the `primitives/sheet_overlay` marker, so they never depend on
  `drawer` (the old tree had 14 libs / 9 components coupled to the handler).
- Barrier default is `black @ 50%` (shadcn `bg-black/50`), not the old
  `black @ 80%`.
- Backdrop scaling/glass (`surfaceOpacity`, `surfaceBlur`) dropped.

Deviations:

- `component_deps: ["dialog"]` from the batch data is **dropped**. The new
  drawer is a self-contained `ModalRoute` (the dialog pilot's pattern) and
  shares no code with `dialog`; declaring it would produce an
  `unused-dependency` warning and violate "deps must match imports".
- The reusable route/shell machinery was moved to the new primitive
  `primitives/drawer_route/` (2 files) so `drawer.dart` and `drawer_style.dart`
  stay ≤ 400 lines (the same escape hatch `primitives/slider/` used). The
  primitive uses `overlay` (`OverlayCompleter`), `sheet_overlay` (marker) and
  `localizations`; the component declares only `deps.primitives:
  ["drawer_route"]`.
- `primitives/sheet_overlay.dart` is unchanged: it still defines
  `SheetOverlayHandler` because `components/card` (accepted B01) imports it.
  Drawer uses the marker, not the handler.

Open questions:

- Drag-to-dismiss drives the route's `AnimationController` directly; the panel
  animates back or pops below the 0.5 threshold. No fling animation beyond
  `easeOut`; acceptable, tested for the close path only.
- `DrawerTheme.borderRadius` is `BorderRadius?` (not `BorderRadiusGeometry?`)
  because the shell performs inner-corner surgery; a directional radius would
  not be representable.

Bugs fixed / behaviours corrected:

- Global mutable state removed: `_defaultToastController` and `_toastSequence`.
  The stack is owned by `ToastLayer` (or an injected `ToastController`).
- Single queue: the shared `primitives/toast_queue` holds the stack; the
  component owns no duplicate controller.
- The documented auto-dismiss policy is implemented in one place: a toast's
  countdown is its own, interaction pauses it, and while a slot holds more than
  one toast every non-newest toast pauses (`_reconcileSlots`).
- The old `OverlayEntry` insertion path is replaced by a `Stack` in
  `ToastLayer`; the upstream `ExpandMode` / `UpstreamToastEntry` shims are gone.

Deviations:

- `primitives: ["overlay", "toast_queue"]` from the batch data → only
  `toast_queue` is imported; `overlay` is unused (the layer renders in its own
  `Stack`), so declaring it would trip `unused-dependency`.
- `ToastBuilder` + `ToastController` were moved into
  `primitives/toast_queue/toast_controller.dart` (shared with the upcoming
  `gooey_toast`, B18) so `toast.dart` fits the ≤ 400-line rule.

Open questions:

- Exit animation is not animated: the queue removes an entry immediately, so
  swipe/close/auto-dismiss disappear instantly while entry is a fade. A future
  pass could keep the card mounted during a reverse animation. Documented in
  the README.
- `pauseOnHover` pauses on pointer-down as well as hover (house rule 2); the
  MouseRegion/Listener pair is exercised only through the queue-level pause in
  tests.
