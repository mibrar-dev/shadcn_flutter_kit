## Round-3 structural fix (QA)

- **Theme classes back in the component.** `TableTheme` and `TableCellTheme` moved from
  `primitives/table_layout/table_theme.dart` (deleted) into `components/table/table_style.dart`,
  which now holds the classes + token defaults + `mergeTableCellTheme` (340 lines). There is no
  re-export of primitive theme types.
- **Primitive imports nothing from `components/`.** Verified by grep: the only `components/` string
  in `primitives/table_layout/` is a code comment.
- **Consequence:** the public models (`ShadcnTableRow` / `ShadcnTableCell`) are theme-free (the
  old per-row `cellTheme` and per-cell `theme` override fields are dropped), because the primitive
  keeps the models and must not reference a component type. Table-level theming is unchanged
  (`TableTheme.cellTheme` merges over the row defaults); no default rendering changed.

### Bugs fixed
1. **Hard-coded white fill** → the `card` token (dark tables were white). Regression test.
2. **Dead `TableTheme.cellTheme`** → now merged under the row defaults (tested).
3. **Per-build closures** in row default themes → const token rows.
4. **Wrong theme source** (`Theme.of(context).colorScheme`) → `ThemedColor` tokens.
5. **`copyWith` dropped `borderRadius`** → fixed.
6. **`hitTestChildren` walked forward** (comment claimed reverse) → walks last-to-first.
7. **Loose flex height budget bug** (`spacePerFlexHeight` written instead of
   `looseSpacePerFlexHeight`) → fixed in `table_layout_sizing.dart`.
8. **Double paint / clip layers** in `paint` → each cell painted once.
9. **Duplicated state** (`_TableState` + `_ResizableTableState`) → `ResizableTable` folded into
   `ShadcnTable`.
10. **Four duplicated resize handles** → one helper.
11. `ignore_for_file`, `part`, `_impl/`, `theme.schema.json` and the config/tokens/defaults files
    are gone.

### Deviations / notes
- `primitives/table_layout/` (8 files) is a new primitive not in the batch's primitive list; it is
  forced by the 3-Dart-file / 400-line component rule (the batch's own target is 1800 LOC) and is
  the same split the accepted `slider` component uses. `meta.json` declares
  `deps.primitives: ["table_layout"]`.
- The batch listed `primitives: ["clickable", "localizations"]`; the table has no clickable cells,
  and `localizations` is used only by the resize-handle semantics in the **primitive**
  (`table_resize.dart`), so it is not declared on the component (that would trip
  `unused-dependency`).
- `ResizableTable` is dropped (clean break); resizing is `ShadcnTable(resizeController: ...)`.
- Per-row/per-cell theme override fields were dropped (round-3 consequence); table-level
  `TableTheme.cellTheme` covers grid theming.
- `table_style.dart` is the component's theme file (classes + defaults); `table_theme.dart`
  (user-owned) imports it and stays values-only.
