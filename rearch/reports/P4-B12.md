# P4-B12 — resizable, sortable, overlay_configuration, drawer_container

Batch B12 (parallel group B). Migrated from `lib/registry/components/**` into
`lib/registry_next/components/**`, plus two new primitives. Every file is
widgets-only, ≤400 lines, and the component folders hold only
`<name>.dart`, `<name>_style.dart`, `<name>_theme.dart` (where a theme
exists), `preview.dart`, `meta.json`, `README.md`.

## New primitives (budget escape hatch)

The component file budget (≤400 lines) could not hold these two reusable
machinery pieces, so they live in primitives and are re-exported by the
component (the same escape hatch `primitives/slider/`, `primitives/file_value/`
and `primitives/toast_queue/` used):

- `primitives/resizable_pane.dart` (171) — `ResizablePaneController`,
  `ResizablePaneHandle`, `ResizableEntryItem`, `ResizablePaneLayout`. Used by
  `resizable`; reusable by any split-pane layout.
- `primitives/axis_size.dart` (120) — the `AxisSize` cross-axis algebra, moved
  out of `drawer_container`; reusable by any edge-anchored panel
  (`pinned_sheet`, B21).

Public API: `ResizablePanelGroup`, `ResizablePanel`, `ResizablePaneController`
(+ `ResizablePaneHandle`/`ResizableEntryItem`/`ResizablePaneLayout`),
`ResizableTheme`, `resizableDefaults`, `resizableThemeOverrides`.

Bugs fixed:
- Material `Divider`/`VerticalDivider` import and defaults removed (batch
  requirement); dividers are themed token lines.

- `_ResizerState._onDragCancel` dereferenced `_dragSession!` and crashed when a

- The `ResizablePaneController` mixin declared `resize(double, double)` while
  `AbsoluteResizablePaneController.resize` overrode it with extra optional
  `minSize`/`maxSize`; the signature is normalized.
- `computeDraggers` sorted the live `_controllers` list in place on every
  compute and matched panes with `widget.children.indexOf` (O(n²)); replaced by
  an index-aligned entry list.
- `details.primaryDelta!` null assert replaced with `?? 0`.

Deviations:
- shadcn composition is *not* used: the group takes `children:
  List<ResizablePanel>` and builds the divider between each pair itself. There
  is no `ResizableHandle` widget (it would have pushed the file over budget).
- `AbsoluteResizablePaneController` / `FlexibleResizablePaneController` merge
  into one `ResizablePaneController` (exactly one of `size`/`flex`).
- `PanelSibling` and `tryExpand`/`tryCollapse`/`tryExpandSize` are dropped;
  `onResizeStart/Update/End/Cancel` are dropped (observe the controller).
- The 481-line custom `RenderBox` is replaced by `LayoutBuilder` + `Stack`.
- `ResizableTheme` grip is shown only while the divider is hovered/dragged.

| Old | New |
|---|---|
| `components/overlay/overlay_configuration/**` (1037) | `components/overlay_configuration/overlay_configuration.dart` (397), `preview.dart` (169) |

Total new 566 vs old 1037 (target 450).

Public API: `OverlayConfiguration`, `showOverlay`, `OverlayController`,
`PopoverConfiguration`, `TooltipConfiguration`, `DrawerConfiguration`,
`SheetConfiguration`, `DialogConfiguration`.

Bugs fixed:
- The old port was a compile-parity shim: every non-popover configuration
  delegated to a modal `PopoverController` behind `@Deprecated` overrides.
  `DrawerConfiguration` / `SheetConfiguration` now drive the real `drawer`
  routes (`openDrawerOverlay` / `openSheetOverlay`); the deprecations are gone.
- `OverlayController.show` had a dead `if (sameType) close(); else close();`
  branch; replaced by a single `close()`.
- The `DelegatedOverlayCompleter` wrapper is gone (the registry's
  `OverlayCompleter` is returned directly).

Breaking change documented in the file + README: custom anchors resolve
through the tree, so a non-`ContextAnchor` needs an `OverlayAnchorScope`
(anchor B06). `ContextAnchor.context` is used to anchor the popover when
available.

Deviations:
- `MenuConfiguration` dropped: it was identical to an adaptive
  `PopoverConfiguration` (mobile → bottom drawer).
- Unused upstream parity parameters dropped (`position`, `key`, `rootOverlay`,
  `clipBehavior`, `regionGroupId`, `transitionAlignment`, `onTickFollow`,
  `animationController`, `autoOpen`, `traversalEdgeBehavior`, `fullScreen`, …).
- `nonAdaptive` is a documented no-op getter (adaptivity is resolved at show
  time via `adaptive: false`).

# Round 2 (QA) — restorations

Two user-visible restorations; the rest of the batch was accepted.

## F1 resizable — `ResizableHandle`

- Restored shadcn's `ResizableHandle` API. `ResizablePanelGroup.children` is
  now `List<Widget>` and alternates `ResizablePanel` / `ResizableHandle`
  (the group no longer auto-builds dividers).
- `ResizableHandle(withHandle: false)` (default) is the 1px themed divider
  with an enlarged (10px) hit area; `withHandle: true` draws the grip bar.
- Keyboard: a focused handle moves with the arrow keys (10 logical px) and
  Home/End jump to the extremes; the step constant is
  `resizableHandleStep`.
- Semantics label from `ShadcnLocalizations.resizableHandle` (added to
  `primitives/localizations/localizations.dart`; English fallback, all locales
  inherit it).
- New primitive `primitives/resizable_handle.dart` (278 lines) holds
  `ResizableHandle` + `ResizableHandleView` + `resizableHandleStep` +
  `resolveResizableHandleColor`; `resizable.dart` is 399 lines.
- Bug fixed while restoring: a tap recognizer on the same `GestureDetector`
  as the drag stole the drag slop (a 40px drag moved the pane 20px); the
  handle now focuses via `Listener.onPointerDown`, so the drag reports the
  full delta.

## F2 sortable — drop settle animation

- Restored `SortableLayer.dropDuration` (default 200ms) and `dropCurve`
  (default `Curves.easeOut`). On drop the ghost glides from its dragged
  position to the target's layer-space slot (or back to the origin on a
  failed/cancelled drop) before being removed.
- The settle is skipped when `MediaQuery.disableAnimations` is true or
  `dropDuration == Duration.zero`.
- New primitive `primitives/sortable_layer.dart` (191 lines) holds
  `SortableData`, `SortableSession`, `SortableLayer` and `SortableLayerState`
  (with the `AnimationController` settle); `sortable.dart` is 355 lines.
- `SortableDropFallback` stays out (as instructed).
