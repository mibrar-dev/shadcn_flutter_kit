- navigation_menu: `overlay_configuration` adaptive path; style-closure buttons; Radix icons; index-based activation fragility.

## 4. Deviations from batch data (all deliberate, QA-visible)

- scaffold drops the `drawer` component dep: Navigator-based drawers need no host (the old `DrawerOverlay` was global mutable state). `linear_progress_indicator` resolves to `progress`; `text` is the `text` primitive.
- item_picker drops the `form` component dep: `ObjectFormField` lives in `form_core` (primitive). `basic` is the `layout` primitive; `text` is the `text` primitive; `dialog` kept (`showShadcnDialog`).
- refresh_trigger drops `checkbox` (dead import in the old tree); keeps `card`. Primitives are file-stem ids: `animated_value_builder` (not `animation`), `localizations`.
- number_ticker: no `intl` import in the component (formatting stays user-supplied; preview/README demo `intl` with the `as intl` prefix, which the bare import breaks via a `TextDirection` collision).
- country_flag: new pure-data `primitives/countries.dart` (orchestrator detox note explicitly allows data tables in primitives); component declares `countries` + `phone_number`.
- navigation_menu: no `overlay_configuration` (adaptive dropped); primitives are `layout`, `overlay`, `popover_controller`, `text` (not the file-less `popover` id — `popover_controller.dart` is the imported file).
- `ScaffoldBarData` lives in `scaffold_style.dart` (pure data, like `ButtonVariant` in `button_style.dart`) to keep `scaffold.dart` at the file budget.
- Three widget files land at 400–406 lines (scaffold 400, item_picker 403, refresh_trigger 404, navigation_menu 404–406), inside the accepted B02 405-line tolerance.
