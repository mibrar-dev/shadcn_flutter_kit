## Structure deviation (why the primitive folder)

The folder cap (3 code files × 400) cannot hold widget + full renderer, and
the batch concedes 3.6k. Reusable/sharable machinery moved to one new
primitive `primitives/markdown_parser/` (justified: B25 text_animate "shares
parser"; it needs `computeStableMarkdownPrefixLength` + the API surface +
block-level rendering): `document` (model/sanitize/slug/stable-prefix),
`block_parser`, `inline_parser`, `api` (public types + render snapshot +
callback bundle), `blocks` (text builders), `media` (table/image/preview),
`view` (dispatch/wraps/region menu), barrel. `meta.json` deps:
foundation [], theme [color_tokens, theme], primitives
[markdown_parser, localizations, text_editing], components [] — matches
imports exactly. Primitive files import downward only (foundation icons,
sibling text_editing); component never imports another component.

Theme cuts vs old (geometry fixed at shadcn consts in the renderer):
`codeLanguageStyle`, `imageCaptionStyle`, `quoteBackgroundColor`,
`listIndent`, `quoteBorderWidth`, `imageMaxHeight`, `tableCellMinWidth`,
`codePadding`, `quotePadding`, `tableCellPadding`, `codeRadius`,
`tableRadius`; `mathStyle`, details/footnote fields with their blocks;
`htmlDefaults`/`chatBubbleDefaults` statics (only user: old global registry,
deleted at cutover) replaced by token-derived `markdownDefaults`.

1. Material import (`material.dart` barrel + `showDialog`/`Dialog`/`IconButton`/`TextButton`/`Icon`/`CircularProgressIndicator`/`Divider`/`SelectionArea`) → widgets-only (`showGeneralDialog`, `SelectableRegion` + shadcn handles, painted rule).

5. `TapGestureRecognizer()` per build, never disposed → state-owned cache, disposed in `dispose()`.
6. Static mutable `_failedNetworkImageUrls` global → per-state `_failedImages` set.
7. `Uri.decodeComponent` unguarded in slugger throws on bare `%` → try/catch fallback (test: `# 100% sure`).
8. `followLinks` platform opener (MethodChannel/`Process`/`dart:html`) → callbacks only; documented `url_launcher` recipe.
9. `SelectionArea` (material) → `SelectableRegion` + `markdownSelectionMenu` (shadcn toolbar adapted to region state); found live: `RichText`/`Image` assert without a selection color when a registrar exists → token-derived `selection` snapshot field (`primary` × 0.2 fallback, selectable.dart precedent); images wrapped in `SelectionContainer.disabled`.
