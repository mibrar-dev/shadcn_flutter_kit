## Bugs fixed

1. **Material sweep (batch-listed).** `gooey_toast.dart` imported
   `package:flutter/material.dart`; the widget used `Icons.*`,
   `CircularProgressIndicator`, `TextButton`, `Material`, `InkWell` and
   `Theme.of`. All replaced: Lucide icons (`foundation/icons`), a rotating
   `GooeyStateIcon` built on `RepeatedAnimationBuilder`
   (`primitives/animation.dart`), a widgets-only `GooeyActionChip`, and
   `ShadcnTheme.of`. Zero Material/Cupertino imports (gate `banned` empty).
2. **Preset-registry scan per build.** `_defaultFillForTheme` iterated
   `registryThemePresets` (42 presets) to reverse-engineer the opposite-mode
   background. Replaced by the const theme default (`#0D1117`); the
   `preset_themes` dependency is gone.
3. **Theme frozen at show time.** The old controller resolved width,
   roundness, tones, animation/shape/body styles from `ComponentTheme.maybeOf`
   when `show()` was called. The new card resolves everything at build, so a
   theme/preset change while a toast is open is live. Regression test:
   `theme changes are live while a toast is visible`.
4. **Touch tap double-toggle.** Pointer-down expanded the body and the tap
   handler then toggled `_expanded` — on touch, one tap expanded and
   immediately collapsed (a visible no-op). Press now only pauses the
   countdown; the tap toggles. Regression test:
   `tapping the pill toggles the body`.
5. **Anchor clamp crash on small viewports.** `_resolveAnchors` used
   `clamp(16, screenWidth - width - 16)`; when the viewport was narrower than
   the toast the lower bound exceeded the upper one and `clamp` threw
   `ArgumentError`. The new stack has no such clamp. Regression test:
   `a viewport smaller than the surface does not crash`.
6. **Duplicate overlay/queue machinery.** The old controller owned its own
   records, `OverlayEntry` insertion, timers and region bookkeeping. The
   component now uses the single shared `ToastQueue` (house rule) and follows
   the documented auto-dismiss policy via `GooeyStack._reconcileSlots`.
   Regression test: `a stacked slot pauses the older toast`.
7. **Covered toasts expired under each other.** `pauseAutoDismissWhenMultiple`
   defaulted to `false`, so a stacked toast's countdown kept running while a
   newer one covered it. Replaced by the mandatory non-primary pause policy.
8. **Swipe dismissal tracked global pointer positions.** The old region
   recorded raw global down/last positions and could dismiss after an
   unrelated drag; no velocity support. New `GooeySwipe` uses local pan deltas,
   per-direction filtering, a threshold and fling velocity. Tests:
   `GooeySwipe` ×3.
9. **Dead stack-control feature removed.** `GooeyToastStackScope` passed
   `setExpanded: (_) {}` and `expanded: false`, so `_stackControlled` was
   always false and the `Collapse`/`Clear all` chips never appeared. Deleted.
10. **Staged `transitionAfterClosed` choreography.** Three timed `show()`
    phases with fallback timers replaced by the queue's in-place `update`
    (`GooeyToastNewToastBehavior.transition`); the pill morphs via
    `AnimatedSwitcher`. Test: `transition updates the newest toast in place`.
11. **`GooeyToastTheme.copyWith` clearing semantics** (`ValueGetter` that
    could not distinguish “keep” from “clear”) replaced by the standard
    nullable-callback `copyWith`.
12. **`_MeasureSize` post-frame callbacks** could fire after disposal; the new
    `GooeyMeasure` is guarded by the state's `mounted` check.

## Deviations

- **`component_deps: ["toast"]` dropped.** The new component imports no symbol
  from `components/toast`; the shared seam is `primitives/toast_queue` (queue,
  entry, placement, auto-dismiss policy). Declaring `toast` would produce an
  `unused-dependency` warning and violate “deps must match imports”.
  `meta.json` `deps.components` is `[]`.
- **Batch primitives:** `toast_queue` and `animation` are used; `overlay` is
  not (the layer renders in its own `Stack`, like the accepted `toast`), so it
  is not declared.
- **`primitives/gooey/` is a new primitive folder** (not listed in the batch
  data) — see the table above. No extra files were added to the component
  folder (`qa_batch` layout check: exactly the six allowed entries).
- **`GooeyToastPosition.centerLeft` / `centerRight` dropped.** The shared queue
  slots have no centre-band anchor (`ToastPlacement` is edge-based), and the
  old positions also carried the clamp bug. `left/center/right` ×
  `GooeyToastExpandDirection` covers the anchor space.
- **`GooeyToastDetails` / `activeToasts` / `containsToast` deleted**; use
  `GooeyToastController.entries` / `entriesIn` / `contains` / `entryOf`.
- **`GooeyCompactMorph` per-show morph config dropped**; the morph uses the
  old defaults (400 ms, `easeInOutCubicEmphasized`, slide `(0, 0.10)`,
  scale `0.80`) in `GooeySurfacePill`.
- **`GooeyToastExpansionPhase` dropped**; `GooeyToastOptions.onExpansionChanged`
  reports `bool` (opening / closed).
- **`GooeyToastSwipeDirection` dropped** in favour of the primitive
  `ToastSwipeDirection`.
- **Stack options dropped:** `overlapStackWhenMultiple`,
  `overlapStackOffset`, `maxVisibleCount`, `dismissWholeStackWhenMultiple`,
  stack control chips. Stacking is spacing-based (`gap: 8`) and the queue
  policy owns dismissal.
- **Theme knobs trimmed:** `pauseOnHover` (always on), `swipeToDismiss` (always
  on), `dismissDirections` (placement defaults), `dismissDragThreshold`
  (`GooeySwipe.threshold`, default 72), `spacing` (stack default 8). The
  remaining fields are listed in `meta.json` `theme.fields`.
- **Default fill and tones are literals** (`#0D1117`, six status accents):
  shadcn has no success/warning/info tokens and the dark pill is the
  component's signature. Both are `ThemedColor` fields, so
  `ThemedColor.ref(ColorRef.*)` overrides follow presets (tested).

## Open questions

- **Literal surface/status colours.** The dark fill and the six tone accents
  are literals because shadcn defines no status tokens; they are
  `ThemedColor`-typed and overridable. If QA prefers a token-derived default
  (e.g. `ColorRef.foreground`), the dark-mode contrast of the tone accents
  needs a design call.
- **Pill width measurement** uses the pre-merge `TextStyle` (the ambient
  `DefaultTextStyle` font family is applied at layout, not to the
  `TextPainter`), so custom fonts can shift the pill width by a few px;
  `Text` ellipsises at worst. Same limitation as the old code.
- **Exit animation is not animated** (the queue removes entries immediately),
  matching the accepted `toast` component's open item.
- **Autopilot rescheduling:** `didUpdateWidget` re-arms the timers when the
  content widgets change identity, so a theme switch mid-toast restarts the
  collapse delay.
- **`primitives/README.md` not updated** with the new `gooey/` folder (outside
  this batch's outputs); the folder headers document each file.
- **Action chip is tap-only** (no hover/press styling or keyboard activation);
  it could adopt `Clickable` later if the chip becomes interactive UI.

## QA round 2 — F1 exit animation, F2 pill width, tones, README

### F1 — exit animation before removal (toast + gooey_toast + toast_queue)

The queue stays the single source of truth: `ToastQueue.dismiss` no longer
removes an entry, it calls `ToastEntry.beginExit()` (stops the countdown,
freezes interaction) and notifies. The entry stays in `entries` with
`ToastEntry.isExiting` set; the component plays the exit animation and calls the
new `ToastQueue.remove(id)`. If nothing confirms the removal, the queue removes
the toast itself after `exitDuration` (200 ms) + `kToastExitGrace` (300 ms).
Related queue rules: `update` ignores an exiting entry; `show` with an exiting
id revives it as a fresh toast and cancels the pending fallback; `dispose`
cancels exit timers.

Presentation (new `primitives/toast_queue/toast_exit.dart`):

- `ToastExitTransition<T>` — fades the child out, slides it towards the dismiss
  direction (0.3 of its size), optionally collapses its vertical extent, and
  calls `queue.remove` on completion. `MediaQuery.disableAnimations` runs it at
  `Duration.zero` and removes after the current frame. `IgnorePointer` while
  exiting.
- `ToastSlotColumn<T>` — the ordered column of a slot: newest nearest the
  anchor, each unit carrying its own gap (so a collapse takes the gap with it)
  and wrapped in the exit transition. Both components share it.
- `ToastPlacement.exitDirection` — `up` for top placements, `down` for bottom.

`toast`: cards are wrapped by `ToastSlotColumn`; a dismissed card fades + slides
+ collapses (unit incl. gap) so the remaining cards animate into their new
positions. `gooey_toast`: `_GooeyToastCard` wraps the surface in
`ToastExitTransition` (fade + slide, no collapse) and `GooeyStack` positions
entries with **keyed `AnimatedPositioned`** (200 ms, `easeInOut`) so siblings
animate into their freed offsets; the stack's slot reconciliation and the
gooey controller's `transition` lookup ignore exiting entries.

Tests (all updated/added):

- `toast_queue_test.dart`: 31 tests — dismiss/remove two-phase, fallback
  removal, `dismissSlot`/`dismissAll` semantics, revive on re-show, `update`
  ignored while exiting, `beginExit` freezes countdown/interaction.
- `toast_test.dart`: 14 — dismissed toast stays mounted while exiting and the

- `gooey_toast_test.dart`: 24 — same three cases for gooey (fade, animated

- `gooey_test.dart` (primitive): stack anchoring settles through

### F2 — pill width measures the painted style

`_GooeySurfaceState.build` now measures with
`DefaultTextStyle.of(context).style.merge(widget.titleStyle)` — the same
ambient + theme style the pill's `Text` paints with, font family included — and
passes that merged style to `GooeySurfacePill`. Regression test
(`gooey_test.dart`): a `DefaultTextStyle` with `fontFamily: 'CustomTestFont'`
and `letterSpacing: 4` widens the pill and the merged family reaches the pill;
without the fix both values were unchanged.

### Tones are theme fields

`GooeyToastTones` was removed; the six accents are now **direct nullable
`ThemedColor` fields on `GooeyToastTheme`** — `successTone`, `loadingTone`,
`errorTone`, `warningTone`, `infoTone`, `actionTone` — with literal defaults
(`#63C65E`, `#8A8F98`, `#EF5E5E`, `#EABB4B`, `#6EA8FF`, `#7A8DFF`). They merge,
copy and lerp per field, are listed in `meta.json` `theme.fields`, and
`GooeyToastState.tone(theme, colors)` resolves them; the user-owned
`gooey_toast_theme.dart` example and the README table were updated.
