## 4. QA round 2 (F1 + F2) — fixed

### F1: bordered controls no longer add 2px

Root cause: `Clickable` paints the `BoxDecoration` border as decoration
padding, which participates in layout, so outline `md` measured 38 instead of
h-9 = 36 (sm 34, lg 42, icon 38).

Fix (single owner `foundation/geometry.dart: insetBorder`):
* the inner minimum reserves `max(padding, border)` per side, and
* the `Clickable` padding is inset by the border width (`insetBorder`),
  so `content + insetPadding + border == size-table total`;
* a declared border always occupies its width (transparent where a state has no
  colour), so hover/press/disabled never change the size.

Applied to `button`, `toggle` and `primitives/navigation/navigation_item_row`
(the same pattern). New tests: button outline/secondary/ghost ×
xs/sm/md/lg/icon heights (28/32/36/40/36) + icon square, hover/press size
stability, hover-only border reservation; toggle bordered sizes (32/36/40);
file_picker's mobile trigger assertion changed 38 → 36.

### F2: restored features

* `file_picker`: `FileUploadItemsView` (`primitives/file_value`, 216 lines)
  restores `layout: list | grid` (`FileUploadItemsLayout`, `gridColumns`),
  grouping by a caller key (`groupKey`, `groupHeaderBuilder`; status grouping
  is `groupKey: (item) => item.status.name`) and per-file icons
  (`iconBuilder`, replacing `FileIconProvider`), plus `itemsMaxHeight`.
  4 new tests (grid columns, default group headers + counts, custom header
  builder, iconBuilder).
* `navigation_bar`: `NavigationGap` (fixed main-axis gap) and `NavigationSlot`
  (leading/title/subtitle/trailing + `onPressed`, using the resolved
  `itemStyle`) restored in `primitives/navigation`; 2 new tests.
* Popover picker and key-based selection stay dropped (documented).
