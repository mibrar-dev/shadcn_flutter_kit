## Bugs fixed (all have regression tests unless noted)

1. **App theme leg ignored.** Old state read widget + scoped legs only
   (`styleValue(widget, theme, default)`); app-wide overrides were silently
   dropped (same class as the `number_ticker` fix). New code resolves all
   four legs per field via `resolveTextAnimateParts`. Tests: app-beats-defaults,
   scoped-beats-app, widget-beats-scoped for style/typewriter/effect/cursor.
2. **`withTextStreaming` cursor silently ignored.** The old adapter accepted
   `cursor` but never rendered it. The parameter is dropped (documented in
   README differences); the plain widget's cursor is fully wired and tested.
3. **Word-split whitespace loss.** Old `_splitToWordUnits` (`\S+\s*`)
   dropped leading whitespace so units no longer joined back to the input;
   the adapter used `\S+\s*|\s+`. Unified on the lossless regex; test asserts
   `'  hi  there '` round-trips exactly.
4. **Adapter/char effect divergence.** The old adapter re-implemented
   fade/blur/slide with different math (own web-only branch, opposite blur
   slide sign). Both paths now share `streamingProgress`; the block path
   (`animateStreamingBlock`) is the same rows without the baseline wrapper
   (verified against the SDK: `RenderBaseline` falls back to child height,
   which would squash a tall column — hence the split). Tests: tail blur
   filter present mid-flight, gone after settle.
5. **Scramble seed `%` crash.** Old `seed.abs() % len` breaks on
   `int.min` (`abs` stays negative → negative index). Euclidean `%`
   directly. Determinism kept (no `Random`): two fresh pumps at the same
   age render identical glyphs (tested).
6. **`onSettled` swallowed on effect swap.** Old and new guard fired once
   per snapshot revision, so replaying the same revision under a new effect
   never reported settling. The mixin re-arms on any return to unsettled.
   Test: the 6-effect loop settles and fires per effect on a reused state
   (this also exercises effect-swap reuse).
7. **Untestable wall clock.** Old `Stopwatch` + `Timer.periodic` reads real
   time, so reveal pacing can never be asserted with fake-async pumps.
   The engine now runs on a vsync ticker (`SingleTickerProviderStateMixin`
   + `StreamingClock`, ~60 Hz throttle): pacing, settle ages and blink
   phases are exact under `pump(duration)`. Timing tests assert real frame
   counts (cps=10 → 1/2/6 units at 0/100/600 ms).
8. **Blur filter stays mounted.** Old char blur kept the `ImageFiltered`
   layer at opacity 0 after settling. The settled frame drops the blurred
   layer (and the tail filter likewise). Tested both paths.
9. Static `_failedNetworkImageUrls`-class globals: none existed here; the
   new code holds no static mutable state (clocks/tickers are per-state,
   disposed). Material imports: none (old entry was already widgets-only;
   the preview's `Scaffold`/`Slider`/`FilledButton` are gone).

## Deviations / open questions

1. **New primitive `primitives/streaming_text/`** (barrel + `streaming_snapshot`,
   `streaming_clock`, `streaming_effects`, `streaming_block`) — not in batch
   data (which lists `animation`, `text`, neither of which the component
   imports: per-char timing needs its own snapshot/clock, and the fluent
   `primitives/text` modifiers are opt-in only). Justification: two public
   widgets share one engine and the component folder cap cannot hold it;
   precedent B16/B24. The primitives README table does not list the folder
   (read-only for this batch) — one-line addition wanted. Ratify placement.
2. **Single `TextAnimateEffect` class** instead of 7 classes, per P4_PLAN §4
   "animation-style rows" (enum + exhaustive switch). Old class names are
   gone (clean break); mapping table above + README.
3. **Dropped `textDirection`/`locale`/`textWidthBasis`/`textHeightBehavior`/
   `softWrap`/`overflow`/`maxLines`** (ambient-covered RichText plumbing;
   `textAlign` kept). Same judgment as the input pilot's ~20-param cut;
   listed in README. Confirm, or restore if apps need them.
4. **`TextAnimateMarkdown` has no cursor/`onSettled`** (old adapter had a
   dead cursor param and no settle callback). Confirm no settle callback is
   wanted on the markdown path.
5. **Block blur is single-layer** while char blur crossfades sharp-over-blur
   (matches the old adapter vs char split). Confirm, or unify on crossfade.
6. **Web blur branch dropped**: old adapter skipped `ImageFiltered` on web
   (`kIsWeb`); both paths now blur everywhere (correct, possibly slower on
   web canvases). Confirm.
7. **Sizes**: fluid text has no fixed logical size (markdown precedent — no
   `getSize` asserts); interaction states hover/press/focus/disabled are N/A
   (non-interactive, no `Clickable`); keyboard N/A (no focusable elements).
   Reduced motion, four theme legs, controlled revisions (append/restart),
   and every old-bug regression are tested instead (49 tests).
8. **`_StreamingSection` memo** (renamed `StreamingSectionCache` in the
   primitive) keeps settled markdown sections out of per-frame rebuilds;
   config changes invalidate via the 16-field `_sameConfig` (dropped old
   fields excluded). New `Markdown` fields are picked up automatically
   through `copyWith`.
