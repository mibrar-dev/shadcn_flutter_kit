## Framework facts found (for other batches)

- `Container` reserves a `BoxDecoration` border as padding: any bordered
  container measures child + 2×borderWidth (checkbox 18 vs shadcn border-box
  16; interactive outline badge 22 vs static 20 via DecoratedBox). Verified
  empirically; do not "fix" per component — it is framework mechanics.
- `FocusOutline` draws in an overflow `Stack` (never affects layout, never
  clips): "padding so the focus ring never clips" is not a reason to pad.
- `Clickable` publishes a default `IconTheme` (24) above its child: tests
  must scope to the nearest scope (accordion chevron case).
- Markdown blank source lines render `SizedBox(height: 8)` blocks.

## Open questions

1. Card/rounded-xl: `radiusXl` = 10 at default tokens vs shadcn 14
   (`--radius` 10 + 4). Token-scale territory (theme batch?) — card asserts
   the token, not px.
2. Badge v4 is `rounded-full`; kit uses `radiusMd`. Deliberate? Left alone.
3. Markdown prose density (14 vs 24 paragraph gap, code pad 12 vs 16,
   heading sizes 28/23/20/18/16/14 vs typography 36/30/24/20): product call.
4. Table header text is `mutedForeground`; v4 `TableHead` is `text-foreground`.
   Color, not size — left alone, flagging.
5. Switch checked travel is `width − thumb` (16, flush right); shadcn
   `translate-x-[calc(100%-2px)]` leaves 2px. Kept kit formula (+ existing
   test); flagging.
6. `check_single_owner` flags `primitives/markdown_parser/media.dart` and
   `file-too-long` flags `slider/slider.dart` (404): both pre-existing /
   untouched by this batch (media.dart untouched; slider was 404 at HEAD).
   `primitives/date_math.dart` + `form_core.dart` modifications in the tree
