## 3. Key decisions and findings (evidence-backed)

1. **`ShadcnApp.router` does not exist** in the post-cutover registry — its
   README states router parameters were dropped ("use `Router`/`RouterDelegate`
   above a plain `ShadcnApp`"). D1 therefore builds: root `Router` →
   delegate builds `ShadcnApp` → `home:` = `DocsRouterHost` (docs navigator).
   The host route is unnamed (custom `pageRouteBuilder` passing
   `const RouteSettings()`) so the inner `WidgetsApp` navigator never reports
   `/` to the engine and cannot clobber deep links.
2. **`Router` does not create a `routeInformationProvider`** — only
   `WidgetsApp` does. Without owning one explicitly, the initial URL was never
   parsed and URL reports were dropped. Found by browser probe
   (`defaultRouteName == /docs/components/button` but the parser never ran);
   `_DocsAppState` now owns/disposes a `PlatformRouteInformationProvider`.
   Regression test: "navigation reports the new URL to the engine".
3. **The docs navigator must rebuild itself.** A navigator captured in the
   shell's route builder froze at the first page stack (deep link parsed,
   state correct, UI not updating — verified in the browser). `DocsRouterHost`
   (`ListenableBuilder` on the delegate) rebuilds `buildNavigator()` on every
   notification; both bugs are covered by tests now.
4. **Persistence: `window.localStorage` via `package:web`, not
   `shared_preferences`.** The docs app is web-only; localStorage keeps the
   pubspec plugin-free and testable (the `DocsStorage` abstraction defaults to
   a no-op off web). This closes P6 plan open question #2 the "replace" way.
5. **Theme tween placement.** `ShadcnApp.enableThemeAnimation` uses
   `kDefaultDuration` (150ms, linear). The shell passes the resolved
   `ShadcnThemeData` to `ShadcnApp` and installs
   `AnimatedShadcnTheme(duration: 300ms, curve: kEaseOutExpo)` through
   `ShadcnApp.builder`, so the spec tween applies to every surface; assert in
   `docs_app_test.dart` (duration + curve + brightness switch).
6. **Hash URL strategy** (engine default, no `usePathUrlStrategy`): deep links
   are `/#/docs/components/button`; nothing extra is needed for GitHub Pages
   (no 404.html shim). Verified in the browser: URL stays hash-based, deep
   links render the right route, and in-app navigation reports new history
   entries.
7. **Palette overlay entry** (`palette_route.dart`): transparent route, 55%
   scrim, scale .97→1 + fade 200ms ease-out-expo, exit ease-in 150ms,
   reduced-motion = fade only ≤150ms. `openPalette()` on the delegate toggles,
   stores the pre-open focus node and restores it on close. D3 owns the panel
   contents (`buildDocsPalette` in `main.dart` is a marked stub); the route and
   toggle/close/focus contract are D1's.
8. **Reduced motion** (`MotionScope`): effective flag = startup
   `matchMedia('(prefers-reduced-motion: reduce)')` probe OR
   `MediaQuery.disableAnimations`; `context.motionDuration/motionOffset` cap
   durations at 150ms and zero out transforms. Started via
   `ShadcnApp.builder`, so every page sees it.
9. **Stub data shape** (`stub_docs_data.dart`): `DocsComponent`, `DocsPreset`,
   `DocsStats`, `DocsSearchKind`, `DocsSearchEntry`,
   `kComponents/kPresets/kStats/kDocsSearchIndex`, plus a temporary
   `buildStubDocsTheme`. These are the names D2 must emit (or must
   coordinate a rename through `main.dart` and the D3/D4 imports — the stub is
   referenced from `main.dart` and `docs_app_test.dart` only).
10. **Mirror includes `preview.dart` (118)** because D4 loads previews via the
    deferred registry and the manifest hashes cover them; `theme/app_theme.dart`
    is protected from deletion (CLI-generated later). `sync_registry.sh
    --check` is CI-ready (rsync dry-run, exit 1 on drift).
11. **`uses-material-design` intentionally absent**: the app bundles zero
    Material/Cupertino fonts. Consequence: `flutter build web` prints a
    benign warning ("Expected to find fonts for …MaterialIcons… found ()")
    because the registry `app` component depends on `flutter_localizations`,
    whose libraries reference those families. No Material widget/import is in
    the tree (gates below). The warning is accepted; alternative is shipping
    ~200K of unused icon font.
12. **`--analyze-size` is not a web flag** in Flutter 3.47 (`Could not find an
    option`). Budget recorded from the artifact instead (below); the metric
    D4/D6 should repeat is `build/web/main.dart.js` raw + gzip.

## 5. Browser smoke test (release build, agent-browser / Chromium)

- `/#/docs/components/button` → renders the component stub; URL unchanged
  (hash strategy), no console errors (`agent-browser errors` empty).
- `/#/themes` and `/` → render the right stubs.
- First paint: inline `docs-first-paint` placeholder appears while CanvasKit
  boots and is removed on `flutter-first-frame` (verified by absence in later
  captures).
- Palette: opened programmatically in a debug build (temporary probe, since
  removed) → scrim + panel render exactly at the top-center, 640px max width;
  `Escape` closes it and the page returns. The final release build is the same
  code path.
- Caveat: the automation harness did not deliver `Ctrl+K`/`Cmd+K` to the
  Flutter view (plain `Escape` was delivered). The shortcut contract is
  covered by widget tests (`Ctrl+K opens the palette and Esc closes it`,
  `palette opens, toggles closed and restores focus`); recommend one manual
  check after deploy.
