## Decisions

1. **Primary-class fallback.** Manifest `api.classes` are honoured after the
   name match and the function path (dialog/popup/drawer keep their
   `show*`/`open*` functions). Within the fallback, a public unnamed
   constructor wins over a private one so the table carries real parameters —
   this is why `formatter` resolves to `TimeFormatter` (the factory set
   `TextInputFormatters` has a private constructor and its static methods do
   not fit the constructor-params model; see open question 3).
2. **Copy JSON** applies the customizer's effective radius (`px / 16`, the
   schema's rem unit) to the canonical preset document. The mode toggle is a
   preview state — both mode blocks always stay in the document, so there is
   no JSON-representable mode edit.
3. **Copy Dart** is the byte-exact `app_theme.dart` `flutter_shadcn theme
   apply <id>` writes (header + `theme.dart` / `color_tokens.dart` /
   `tokens.dart` imports + the preset blocks). The CLI has no radius flag, so
   a radius edit is not applied to the Dart payload; the generated file is
   the canonical CLI output.
4. **Get Code** copies `flutter_shadcn theme apply <id>` (the command that
   regenerates the Dart file in a project) with the same 2 s feedback.
5. **`kRelatedIds` removed** from the codegen: the spec dropped related
   cards, no page consumed the map.
6. **Popper animation** is a 100 ms opacity fade (no transform), so the
   reduced-motion contract ("no transforms, opacity-only ≤150 ms") needs no
   special branch; `AnimatedSwitcher` also animates the close.
7. **Tab traversal fix belongs to the docs app today**: the registry
   `ShadcnApp` API footgun (replacing WidgetsApp defaults) should be fixed in
   the registry (merge instead of replace); the docs app compensates for now
   (open question 1).
8. **Reduced motion** caps every >150 ms docs animation: theme tween 300→150,
   heading anchor 200→150, palette 200→150, scroll-to 250→150. The 100 ms
   popper fade and the 2 s copy timer are unaffected (timer, not motion).

## Open questions

1. **Registry `ShadcnApp` shortcuts/actions replace WidgetsApp defaults** —
   passing either parameter kills Tab traversal, Enter/Space activation and
   Escape app-wide. The docs app spreads the defaults back in; the registry
   component should merge them so consumers do not have to know this.
2. **Tab order in the persistent shell**: the header/footer live outside the
   docs navigator, so the first Tab enters the page content and the header is
   reached after it (framework policy-group ordering). All elements are
   reachable with a visible ring (tested), but the reference site's DOM order
   is header-first. A proper fix needs a shell restructure (chrome inside the
   navigator) or a framework workaround — UNVERIFIED which is acceptable.
3. `formatter`'s API table documents `TimeFormatter(length)` (the first
   constructible manifest class); the primary `TextInputFormatters` factory
   set would need a static-factory table model.
4. `color`'s table has a symbol + summary with 0 parameter rows
   (`ColorDerivative`'s unnamed constructor takes none); its factories and
   static helpers are not modelled — consistent with the 3 pre-existing
   zero-parameter tables.
5. A synthetic 50-deep retained route stack laid out at 1024 produced a
   "BoxConstraints has a negative minimum width" assert (not reproducible
   with a fresh tree per route/width; the smoke test resets between cells).
   Suspect: `primitives/table_layout/table_layout_sizing.dart`
   (`maxWidth - fixedWidth` with a tiny constraint). UNVERIFIED widget.
6. `flutter build web` warns about missing Material/Cupertino icon fonts
   (tree-shaker sees the families via `flutter_localizations`/`intl`); no
   docs or mirror source references those icon classes. Pre-existing.
7. `/docs/theming` and `/docs/dark-mode` are still `DocsPlaceholderPage`
   (D4 scope gap). They pass the responsive matrix but have no content.
8. `main.dart.js` size after the +287 KB `docs_preset_sources.dart` was not
   re-measured (D1's budget note is the last recorded number).
