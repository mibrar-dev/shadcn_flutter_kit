# P6-D6 — UI Check (build-time visual QA vs shadcn reference)

Rebuild-time visual QA of the Flutter docs site (`docs/build/web`, hash routing)
against 115 reference captures of ui.shadcn.com. Every route is captured at
1440 + 375 × light + dark (88 matrix shots) plus 11 state shots (spec §2.8),
compared numerically (PIL mean-abs-diff + %-pixels-differing) and reviewed as
side-by-side ref|ours montages in `rearch/design/ours/montages/`.

Scope: docs pages / widgets / shell only. The registry mirror
`docs/lib/ui/shadcn/` is never edited; registry issues are reported only.

## Method

- Release build served via `python3 -m http.server 8777` from `docs/build/web`.
- Theme forced via `localStorage.setItem('docs.theme.brightness', mode)` + reload.
- Full-page refs beyond 16000 px captured via the tall-viewport trick, clipped at CAP=16000.
- Ref full-page heights hardcoded per route (Flutter canvas makes `scrollHeight` unreliable).
- Metrics + montages generated by `/tmp/d6_compare.py`; montages are the review artifact.

- Pre-existing font warning in the release build (`LucideIcons, RadixIcons, CupertinoIcons, MaterialIcons` referenced; only Lucide + Radix present) — appears in build output, unrelated to this batch.
- Ref full-page heights for `datatable` (28296) and `cli` (24802) exceed our 16000 capture clip; ours are clipped, not shorter.
