# P7-D1 — per-example Preview | Code cards + preview UI polish

## What changed

Component pages now follow the shadcn docs layout: the first named example
("Default") is the main demo card on top, then Installation, Usage, then an
**Examples** section where every remaining example renders as
`### <Name>` + optional description + its own framed card. Each card has its
own Preview | Code tabs (code keeps the faded "View Code" teaser + expand),
a per-card light/dark toggle, and a copy button. Examples register as `h3`
anchors, so the right-hand "On This Page" TOC lists them. The P6-F4 example
`Select` is removed.

### Codegen (`docs/tool/**` → `lib/generated/docs_example_sources.dart`)

- NEW `tool/src/example_sources.dart`: for every
  `const <camel>Previews = [ComponentPreview('Name', _builderFn,
  description: ...)]`, extracts the example builder's source plus the
  transitive closure of the private helpers it uses from the same preview
  file (top-level functions/classes/state classes/variables, analyzer AST,
  file order, doc comments kept). Imports are rewritten to the installed
  layout (`package:<your_app>/ui/shadcn/...`); the docs-only
  `foundation/component_preview.dart` import is dropped.
- NEW `tool/src/render_example_sources.dart`: renders
  `DocsExampleSource{name, description?, builder, code}` and
  `kExampleSources` (118 components, 296 examples).
- `render_common.dart` (`DocsModel.exampleSources`), `model_build.dart`
  (build + bundle entry), `gen_docs_data.dart` (exports).
- Verified: 296/296 entries — names match `kComponentPreviews` one-to-one,
  every `code` contains its `builder` and the widgets import; `--check`
  green (13 files).

### Widgets (`docs/lib/**`)

- NEW `widgets/example_preview_card.dart`: `ExamplePreviewCard` (toolbar:
  registry `Tabs` Preview/Code left — roving focus + arrow keys; toggle +
  copy right; stacks vertically <360 px), `ExampleSnippetCode` (runtime
  `syntaxTextSpan` highlighting, selectable, copy), `_LazyPreview`
  (below-fold cards stay a same-height placeholder until scroll settles;
  deferred chunk still loads once per component and is shared).
- NEW `widgets/component_examples_section.dart`: `ComponentExamplesSection`
  (`## Examples` + per-example `###` + card; empty for ≤1 examples).
- `widgets/component_preview_card.dart`: main demo = first example card;
  gallery-only components keep a bare stage. `PreviewExampleLoader` kept
  (shared by all cards). `Select` controls + `PreviewSnippetCode` removed.
- `widgets/preview_stage.dart`: frame radius → `rounded-lg`; stage takes
  `minHeight` (350 main / 200 examples, `DocsMetrics.previewStageHeight`
  default so the render audit is unaffected), responsive padding (40
  desktop / 16 <640 px), subtle dotted-grid background from the border
  token. Bounded-width semantics unchanged.
- `pages/component_page.dart`: order = demo, Installation, Usage,
  Examples, API, Members?, Theme?, Accessibility?.
- `widgets/docs_article.dart` (**out-of-brief, see below**): pager buttons
  cap long neighbour labels with ellipsis (pre-existing overflow).

`component_sections.dart`, `live_preview.dart`, `code_teaser.dart`,
`code_figure.dart`: no changes needed (teaser/figure reused as-is).

## D1b — preview card polish (centring, single-row toolbar, DocsState removal)

### What changed

Centring is fixed in the examples (not the stage): the stage keeps its
bounded centred box (`Container(alignment: center)` + `ConstrainedBox` +
`Align.center`, no `IntrinsicWidth`), and the left-anchored examples are
centred by design, capped so they never stretch or overflow:

- `flutter_shadcn_kit/lib/registry/components/button/preview.dart`: 4×
  `Align(centerStart)` → `Align.center` (`_buttonExample`, `_buttonIcon`,
  `_buttonLoading`, `_buttonDisabled`); `Wrap` examples unchanged.
- `.../badge/preview.dart`: `Column(start)` → `Column(center)` (both badges
  centred).
- `.../calendar/preview.dart`: panel `Column(start)` → `Column(center)`.
- `.../input/preview.dart`: all 4 examples wrapped in
  `ConstrainedBox(maxWidth: 400)` (was full-bleed); centred, phones fill.
- `.../card/preview.dart`: 3× `SizedBox(width: 320)` →
  `ConstrainedBox(maxWidth: 320)` (was fixed, overflowed 375).
- `.../tabs/preview.dart`: checked, unchanged (`SingleChildScrollView`
  scrolls the 344 px strip on 375 instead of overflowing; the stage centres
  the scroll view).
- Table/alert/accordion: checked, unchanged (explicit max widths 460/512/420,
  already centred).

I tried `Center` + `IntrinsicWidth` in `PreviewStage` first and reverted it:
the all-pages sweep failed with "LayoutBuilder does not support returning
intrinsic dimensions" — intrinsics query every example's subtree and throw
for any example containing a `LayoutBuilder`. `UnconstrainedBox` (unbounded)
was rejected for the same reason (breaks `EditableText`-based inputs).
Example fixes need no intrinsics and no unbounded constraints.

Toolbar (`docs/lib/widgets/example_preview_card.dart`): always one row at
≥ 320 px — `Flexible(flex: 10)` tab strip (horizontal scroll when the 192 px
strip exceeds the leftover) + `Spacer` + icon-only toggle + copy. The toggle
is `Button(outline, sm)` with `Icon(sun/moon, 14)` inside a registry
`Tooltip('Switch to light/dark')` (was `outline sm` icon + `Light/Dark`
text); `CopyButton` unchanged. The `<360 px` wrapping branch is gone.

`DocsState` (`docs/lib/state/docs_state.dart`): removed the now-write-only
preview-selection/invert APIs (`_previewExamples`, `_previewInverted`,
`previewExampleFor`, `setPreviewExample`, `isPreviewInverted`,
`setPreviewInverted`, `togglePreviewInverted`); cards keep per-card local
state. Removed their two tests from `docs/test/docs_state_test.dart`.

Tests: rewrote the `component_page_test.dart` per-card toggle test for the
icon-only toggle (no `Light`/`Dark` text; flip proved by the calendar paint
test in `component_preview_f4_test.dart`); added D1b tests to
`component_examples_test.dart` (loader centre == stage centre ±1 px both axes
+ inner content dx ±1 px for button/badge/input/table/tabs/calendar/card/
alert/accordion at 1440/375; toolbar single row at 320/375 with icon-only
assertions). Tabs inner dx is skipped at 375 (strip wider than stage,
scrolls; loader still centred, no overflow).
