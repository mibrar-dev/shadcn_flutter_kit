# P7-Q0 — sidebar classification (listed/hidden) + parity vs origin/main

Rule (brief P7-Q0): only widgets a developer would drop into a normal app screen
belong in the docs sidebar/index/CMD-K. Parts that exist mainly to build other
widgets are hidden (`"listed": false`, still installable). Decision inputs per
component: reverse deps from `meta.json` (`deps.components`), top-level status
in shadcn/ui, direct app-usability. Components under edit by other agents were
NOT touched (recommendations only, Table C).

State: HEAD already hid 21 (`Utilities (building blocks)`); the crashed P7-Q0
session added 14 more (color_field, color_input, drawer_container, eye_dropper,
outlined_container, scrollable, scrollview, selectable,
spell_check_suggestions_toolbar, stage_container, swiper, switcher, triple_dots,
window — each also recategorized to `Utilities (building blocks)`). Total hidden
now: 35/118. This session verified all 118, made no further meta edits (none
needed), regenerated manifest + docs data/mirror, ran gates.
