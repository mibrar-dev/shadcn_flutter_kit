## Method

1. **Generated previews gate** — `test/registry/previews_test.dart` already pumps every one of my 37
   `preview.dart` lists at 720x420 and 375 wide, neutral+claude × light+dark, asserting no exception and no
   overflow. Re-run, not re-written.
2. **Behaviour** — drive each example in a widget test (tap, Tab/Enter/Space/Arrow/Escape, typing, drag),
   open overlays it owns, assert callbacks and visible state change.
3. **Spacing** — compare measured padding/gap/height against the shadcn Tailwind value × density
   (`Density.compactDensity` 8/8/4, `defaultDensity` 16/16/8, `spaciousDensity` 20/20/10).
4. **Theme** — light/dark × neutral/claude token colours, no hard-coded colour, no invisible text.
5. **Robustness** — 375 / 768 / 1440 widths, no overflow/exception, RTL, reduced motion.
6. **Docs page** — serve a locally built release of `$DOCS`, open `/#/docs/components/<id>`, watch the
   browser console while switching every example (Select) and the light/dark toggle.
